# Reasoner Applications

Community and external applications using the Cosmos 3 Reasoner tower for
image/video understanding, VLM tasks, reasoning, and grounding.

## Environment Setup

All applications use the shared backend setup from
[`cookbooks/cosmos3/README.md`](../../README.md). Follow the section for the
backend your application uses (vLLM, NIM, Cosmos Framework, or Transformers).

## Contributing

To add a new Reasoner application, create a directory here with your application
name (e.g., `worker_safety/`) containing a `README.md` and notebook following the
[Contributing Guide](../../../../CONTRIBUTING.md).

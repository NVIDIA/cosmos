# Cosmos 3 Applications

Community and external applications built on Cosmos 3. Each application is a
self-contained directory with a README, one or more runnable notebooks, and
sample outputs showing expected results.

## Structure

Applications mirror the tower layout used by the core cookbooks:

```
applications/
├── reasoner/          # Reasoner applications (VLM, understanding, reasoning)
└── generator/         # Generator applications
    ├── audiovisual/   # T2I, T2V, I2V, audio
    ├── action/        # Policy, forward/inverse dynamics
    └── transfer/      # Video-to-video transfer
```

See the [Contributing Guide](../../../CONTRIBUTING.md) for the directory

open-access data, one-click runnable, results section, and author attribution.
